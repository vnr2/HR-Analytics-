Project Objective

The objective of this HR Analytics project is to solve these challenges using data visualization and analytics through Tableau and Power BI. The project aims to:

* Analyze historical HR data to uncover patterns in attrition, performance, and satisfaction
* Identify key factors contributing to employee turnover and disengagement
* Provide insights into hiring trends and department-level dynamics
* Deliver interactive dashboards that empower HR leaders to make informed, proactive decisions

By turning raw data into visual insights, this project equips the HR department with the tools to reduce attrition, improve employee engagement, and optimize workforce planning—ultimately contributing to a healthier organizational culture.

Tools & Technologies used:
1) Power BI- Data Transformation, Modeling, Interactive Dashboards
2) Tableau - Visual Storytelling and Deep-dive visual analysis
3) Microsoft Excel - Initial Data Exploration and Preprocessing

Key Insights include:

* Department wise Attrition
* No of Employee by Age Group
* Job Satisfaction Ratings
* Attrition Rate by Gender of Different Age Groups
* Education field wise Attrition
